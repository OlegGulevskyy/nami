Nami 1.1.2

A simpler dictation interface with dedicated vocabulary editing and recording shortcuts that keep working after the window closes.

  • Adds Vocabulary to the sidebar, with automatically saved names and technical terms.
  • Simplifies Models to on-device Parakeet and cloud dictation through Groq. Parakeet runs independently of Whisper.
  • Streamlines settings, model downloads, history, and light and dark appearances. Removes the Playground and About pages.
  • Keeps Nami and recording shortcuts running when its window closes. Use Command-Q to quit.
  • Includes Accessibility alongside Microphone and Input Monitoring in required permission setup.

Upgrading

Existing selections other than Parakeet and Groq switch to on-device Parakeet. Download Parakeet in Settings → Models if needed. Server-based cleanup switches to automatic cleanup. Copy and paste on completion are enabled.

Sidebar shortcuts are now Command-1 for History, Command-2 for Vocabulary, Command-3 for Snippets, and Command-4 for Actions.

Requires an Apple Silicon Mac running macOS 14 or later. Groq requires internet access and a provider API key.

Install through Nami → Check for Updates, or download the app from the GitHub release once its build completes.
